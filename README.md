# Data-Intensive-Systems-Assignment-2
Distributed database system for tracking user's sports progress

## Demo video
https://youtu.be/0CIAOIdP2os

## Guide for running the system:
Prerequisites:
- Docker desktop

1. Open Docker desktop
2. Change `.example.env` -files' names to `.env`. There are one in the `root` folder, one in `backend/` folder, and one in the `frontend/` folder.
3. In the root folder of the project run:
```sh
docker compose up -d
```
